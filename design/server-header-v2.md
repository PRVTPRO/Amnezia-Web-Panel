# Шапка страницы сервера — дизайн v2

Выложено на SERVERA (`https://cnacu6o.duckdns.org:5000/`, ветка `deploy/v188-access`)
2026-11-10. Бэкап прод-шаблона: `/root/Amnezia-Web-Panel/backups/header-v2-20261109-221201/`.
Локальная копия и прод используют один и тот же контракт разметки (`srv-header__*`), но в этом PR
кнопка «Проверить» не возвращена: upstream уже удалял её коммитом `20fc73c` как дубль, а проверка
запускается при загрузке страницы и через управление сервером. Вёрстка адаптирована под такой набор
контролов — на мобильном плашка «Плагины» занимает всю ширину.

## Смысловые зоны

1. **Идентификация** — градиентная плитка с иконкой сервера, имя, `host:port · user`.
2. **Состояние и проверка** (справа сверху) — `Загрузка`, `Ключ SSH`, `Плагины`, `Проверить`.
   Загрузка, ключ и плагины — тихие ghost-кнопки с точкой состояния; «Проверить» — обычная
   secondary-кнопка, единственное действие этой зоны.
3. **Сеть** — чипы IPv4 / IPv6 / Docker IPv6 с семантическим цветом и иконкой,
   справа — «Настроить IP» рядом с данными, которые он меняет.
4. **Сервисы и управление** (нижняя полоса после разделителя) — статусы SSH и Docker слева,
   действия `Шаблоны` (primary), `Управление`, `Конфигурация`, `Импорт из wg-easy` справа.

## Иконки

Все иконки — инлайн-SVG в стиле Lucide (`templates/_ui_icons.html`), 13–24 px,
`stroke="currentColor"`, поэтому автоматически подхватывают цвет темы.
Эмодзи из шапки убраны. Для чипов сохранён семантический ключ в `data-glyph`.

## Темы

Используются только токены `static/css/style.css` (`--bg-*`, `--text-*`, `--success-*`,
`--warning-*`, `--danger-*`, `--accent-gradient`). Отдельных цветов под тему нет,
поэтому светлая и тёмная темы согласованы автоматически.

## Адаптивность

| Ширина | Поведение |
|--------|-----------|
| > 960 px | имя и инструменты в одну строку, чипы под ними |
| ≤ 960 px | инструменты уходят под идентификацию |
| ≤ 640 px | инструменты — сетка 2 колонки; «Плагины» и «Проверить» на всю ширину; действия — 2×2 |
| ≤ 420 px | длинные подписи статусов переносятся, иконки остаются |
| 360 px | проверено: обрезки текста и горизонтального скролла шапки нет |

## Особые состояния

- **Сервер недоступен.** `/ip-status` возвращает пустой payload; строка чипов
  скрывается вместе с кнопкой «Настроить IP», чтобы не показывать ложный зелёный
  `IPv4 · Инстансы: 0 · Пиры: 0` и не предлагать настройку без связи.
  Единственный сигнал — красный бейдж «Ошибка подключения».
- **SSH-ключ требует внимания.** `urgent` — янтарная кнопка
  «Проверить ключ SSH срочно»; `changed` — красная «Ключ SSH изменился!».
  Классы и тексты выставляет существующая `setSSHTrustButton()`, вёрстка только
  перекрашивает кнопку и сохраняет её в одном ряду с остальными.
- **Есть обновления плагинов.** Класс `is-update` от `setAwgPluginButton()`:
  зелёная кнопка «Плагины · есть обновления» с пульсирующей точкой.
  На мобильном она занимает всю ширину строки.
- **Длинное имя сервера.** `overflow-wrap: anywhere` в заголовке.

Все четыре состояния отрисованы в обеих темах, desktop и mobile:
`design/server-audit/state-{normal,ssh-urgent,ssh-changed,plugin-update,both-alert}-{desktop,mobile}-{dark,light}.png`
и контактные листы `sheet-states-*.png`.

## Скриншоты

- `design/header-v2-page-{dark,light}.png` — страница целиком.
- `design/server-audit/` — все 10 серверов, desktop dark/light + mobile dark,

Результат: 56 passed (29 + 27). Playwright-аудит: 10 серверов, 0 ошибок консоли,
0 переполнений самой шапки на всех шести ширинах.

Прод-проверка после выкладки: Jinja-компиляция, рендер `/server/0` через TestClient —
`200`, 74 маркера `srv-header`; `node --check` для всех inline-скриптов отрендеренной
страницы — код 0; `amnezia-panel` — `active`; HTTPS — `302`.

**Крос-веточная особенность:** на проде базовый `.ip-chips` был `flex-direction: column`
(старая шапка). Новый шаблон обязан задавать `.srv-header .ip-chips { flex-direction: row;
flex-wrap: wrap; }`; иначе чипы складываются в столбик. Исправлено и проверено на живом
`/server/0`: высота шапки 183 px, чипы в одну строку, переполнений нет.
