IPv4 / IPv6: сервер → новые инстансы → пиры

Серверная настройка показывает, какие версии IP доступны и что уже используется; селектор разрешает IPv6 новым инстансам. Инстанс без пиров можно переключить в IPv4-only. Новый инстанс наследует IPv6 автоматически. Кнопка «Применить» при необходимости перезапускает Docker (не весь сервер).

В шапке — компактные чипы: IPv4 используется, IPv6 доступен на хосте, Docker IPv6 выключен. «Настроить IP» открывает модалку с деталями и селектором режима. Строка #serverIpv6 в продукте удаляется — источник статуса IPv6 один: /ip-status.

Разрешить IPv6 для новых инстансов
Существующие инстансы не меняются. IPv6 у существующего включается только в его настройках и только пока в нём нет пиров.
⚠
Docker IPv6 ещё не включён
Настройка сохранена, но контейнеры не получат IPv6, пока Docker не перезапущен. Перезапуск затронет все контейнеры на сервере: VPN-сессии отвалятся на 10–30 секунд, панель продолжит работать (она под systemd, не в Docker).

«Используется» = есть хотя бы один пир с IPv6 (in_use). Включён, но пиров нет = «готов, клиентов пока нет» (оранжевый). Переключатель IPv6 у инстанса активен только при 0 пиров.
Если IPv6 на хосте нет — карточка IPv6 серая, селектор disabled с подсказкой «На хосте нет глобального IPv6». Если Docker уже включён — предупреждение и кнопка рестарта исчезают, вместо них зелёный статус «Docker IPv6 включён».

Выдавать IPv6-адреса клиентам
Снимите флажок — инстанс будет выдавать только IPv4. Пока пиров нет, это безопасно.
вкл
⚠
У существующих клиентов IPv6 перестанет работать. IPv4 не затрагивается.
Флажок стоит в блоке DNS IPv6 — там, где настраиваются DNS. При 0 пиров его можно снять: инстанс станет IPv4-only. При наличии пиров он виден, но заблокирован с пояснением. При exit-linked и пирах>0 показывается предупреждение о ремонте.

IPv6: включён автоматически
Сервер разрешает IPv6, Docker IPv6 работает. Новый инстанс получит fd42:8:3::/64 и будет выдавать клиентам IPv6-адреса. Отключить можно в настройках инстанса, пока в нём нет пиров.
авто от сервера
Если серверный флажок выключен: блок серый, текст «IPv6 выключен на сервере — инстанс будет IPv4-only». Если включён, но Docker ещё не перезапущен: «IPv6 применится после рестарта Docker».

6 · Что меняется в конфигах
результат, который увидит клиент
Серверный конфиг инстанса
# было (IPv4-only) Address = 10.8.1.1/24 # станет (dual-stack) Address = 10.8.1.1/24, fd42:8:1::1/64 # DNS6 = 2a10:50c0::ad1:ff
Клиентский конфиг
# было Address = 10.8.1.37/32 DNS = 94.140.14.14, 94.140.15.15 # станет Address = 10.8.1.37/32, fd42:8:1::25/128 DNS = 94.140.14.14, 94.140.15.15, 2a10:50c0::ad1:ff
Существующие пиры IPv6 не получают автоматически: серверный конфиг и AllowedIPs уже созданных пиров не переписываются. Для старых пиров нужна отдельная миграция или новый инстанс.
